海外旅行の準備で、迷うのが「現金はどのくらい持っていくか」ではないでしょうか。私は妻と、2025年8月から世界一周で、20カ国を歩きました。保険のためのカード4枚と、日常用のカード1枚を持っていきましたが、**カードが使えず、現金が必要な場面**は、何度もありました。

この記事では、**私が実際に困った場面**を、国ごとにまとめます。

## 結論：私がやったこと

- **ローカルの食堂、屋台、乗合バス、小さな商店**は、現金のみのことが多かったです。
- **ATMでの引き出しや、クレジットカードのキャッシングは、手数料が高く感じました。** ベトナムとラオスでは、少しだけ引き出しましたが、途中からは、**手持ちの現金と、路上書道でいただいたチップ、カードの支払い**で回しました。
- **ヨーロッパは、カードで払える場面が多く、現金がほとんど要りませんでした。**

以下は、私の体験で、国や場所、時期によって、違うことがあります。

## カードが使えず、現金だった場面（私の場合）

| 国 | カードが使えず、現金だった場面 |
| --- | --- |
| ベトナム | ローカルの食堂 |
| ラオス | バス（鉄道の駅からルアンパバーン市内へ）、ローカルの食堂、屋台 |
| タイ | 一部の屋台 |
| マレーシア | ローカルの食堂 |
| ネパール | ローカルの食堂 |
| インド | ローカルの食堂、オートリキシャ |
| ペルー | コレクティーボ（乗合バス・乗合タクシー） |
| ボリビア | ミニブス（乗合バス）、街中の小さな商店、路上での販売 |

同じ国でも、**都市や、お店の種類**で違います。たとえば、ネパールでも、配車アプリのInDriveは、**カードで払えました。**（[InDriveの使い方](/articles/indrive-nepal-danang)）ウズベキスタンの地下鉄も、**クレジットカードで乗れました。**（[タシケント空港→市内の行き方](/articles/uzbekistan-airport-city)）

## ボリビア・ラパスの宿：ドルでの請求になった話

ボリビアのラパスには、道路封鎖（デモ）のため、**1か月ほど、足止め**になりました。そのとき、**宿の支払い**で、少し驚きました。

- Booking.comには、**ボリビアーノの金額**が表示されていました。
- 宿では、その金額を、**ボリビアの銀行のドルのレートで計算し直した金額**で、請求されました。
- **ドルで払えない場合は、そこから、もう一度ボリビアーノに換算する形**でした。
- その結果、**Booking.comの表示より、高い金額になりました。**（差額は、覚えていません）
- **現金で払うほうが、安く**なりました。クレジットカードで払うと、**カードの手数料が上乗せされる**ためです。（金額は、覚えていません）

これは、**私が泊まった、ある宿の場合**です。ボリビアの宿が、すべてそうとは限りません。予約するときは、**支払い方法と、通貨の扱いを、宿に確認しておく**と安心です。

### ラパスの宿の料金メモ

同じラパスで、泊まった宿の料金は、次のとおりでした（円は、そのときの請求額です）。

- Booking.comのホテル：**1泊 約2,400円**（8泊）
- Airbnbの個室：**1泊 約2,200円**（3泊）
- Airbnbの、1ベッドの部屋まるごと：**1泊 約3,000円**（3泊。割引後）

部屋の種類や、時期が違うので、**単純には比べられません。** 私の場合は、**Airbnbの個室が、少し安い**と感じました。

また、ラパスでは、**延泊すると、料金が高くなりました**（理由は、分かりません）。

なお、フランスのリヨンでは、Airbnbを**長期で予約したほうが、安く**なりました。食費も合わせると、ホテルやドミトリーより安く抑えられました。

## 現金を引き出すとき：手数料が高かった

現金は、ATMや、クレジットカードのキャッシングで、手に入れる方法もあります。ただ、私は、**手数料が高く感じました。** ベトナムとラオスでは、少しだけ引き出しましたが、**金額は、覚えていません。**

そこで、途中から、次の3つで回しました。

1. **手持ちの現金**
2. **路上書道でいただいた、チップ**
3. **クレジットカードの支払い**

## 両替：手数料を聞いて、レートを見比べた

両替は、国やお店によって、**レートが違いました。** そのため、どこの国でも、次のようにしていました。

1. 両替所では、**手数料が含まれているかを、必ず聞く。** 手数料がかからない所で、換える。
2. 空港などで、最低限だけ換えたら、**街に出て、換金所を探す。**
3. **何軒か回って、レートを自分の目で見て、比べてから**、換える場所を決める。

「どの国が安い、高い」とは、一概に言えません。同じ国でも、**お店によって、大きく違いました。**

## 持っていったカード4枚

**利用付帯の保険**のために、出発前に、**4枚**のカードを用意しました。日常の支払いには、日本で普段使っていた**楽天カード**を使いました。

| カード | 付帯保険 |
| --- | --- |
| エポスカード（VISA） | 利用付帯 |
| リクルートカード（JCB） | 利用付帯 |
| リクルートカード（Mastercard） | 利用付帯 |
| Amazonカード（Mastercard） | 利用付帯 |

「利用付帯」は、旅行費用などを、そのカードで払った場合に、保険が使える条件のことです。

**条件は、カードごとに違い、変わることがあります。** 私たちが出発した2025年8月は、出国後の現地の公共交通機関などの支払いでも、保険が有効なカードがありました。ところが、**私が公式サイトなどで確認した2026年10月時点では、エポスカード以外は、出国前の支払いが条件**になっていました。【公開前に、公式の文面で最終確認】

カードの保険の条件は、**必ず、カード会社の公式サイトで、最新の情報を確認**してください。（私は、マレーシアで、条件を確認しておらず、保険が使えませんでした。その体験は、[はじめまして](/articles/hajimemashite)にも書いています。）

## Revolut：契約しておけばよかったと思ったこと

出発前に、契約しなかったものがあります。路上書道のとき、、**「カードで払いたい」**と言ってくださる方が、多くいました。Revolutを持っていれば、**カードで受け取れた可能性**があると思い、契約しておけばよかったと感じました。

私は使っていないので、使い方や手数料は、書けません。

- カードの保険の条件は、変わることがあります。最新の情報は、カード会社の公式サイトでご確認ください。

## 向いている人・向かない人

- **この記事が役に立つ人：** 東南アジアや南米の、ローカルの食堂や乗合バスを使う旅をする人。現金とカードの割合に迷っている人。
- **向かない人：** 現金を使わない、ヨーロッパなどの都市だけを回る人。
