世界一周の途中、マレーシアで熱を出して、カード付帯の海外旅行保険が使えず、[約5万3千円を自腹で払いました](/articles/travel-insurance-card-kl)。原因は、保険の条件が改定されていたのに、気づかなかったことでした。

この経験から、旅に持っていったカードの保険の条件を、あらためて公式ページで調べました。この記事では、私が持っていったカードのうち、リクルートカード、エポスゴールド、Amazon Mastercardを比べます。

## 結論（2026年11月4日に確認）

- どちらも、カードで払うことが条件の「利用付帯」です。持っているだけでは、保険は付きません。
- リクルートカード（Visa・Mastercard）は、公式ページに「日本出国前に、対象の料金をカードで払うこと」と書かれています。出国後の支払いは、対象外と書かれています（2025年12月1日以降の出発から）。
- エポスカード（Visa）とエポスゴールドは、どちらも、公式ページに、条件の1つとして「出国後に、公共交通機関の乗車代金を払う」ことが書かれています。Visaとゴールドで、この条件は同じです。出国後の支払いでも、払った時から90日が補償の期間です。
- Amazon Mastercard（クラシック）（三井住友カード発行）は、Amazonの公式ページに「事前に旅費などを、このカードで払うことが前提」と書かれています。出国後の支払いが対象かどうかは、Amazon Mastercardのページでは確認できませんでした。出国前に払う前提で考えるのが、安全だと思います。
- 私は、エポスゴールドで、現地の公共交通機関の代金を払い、この条件を満たしていました。保険を使ったことは、ありません。
- 一方、Amazon Mastercard（クラシック）は、マレーシアの病院の支払いに使い、保険が適用されず、自腹でした。同じ「カード付帯の保険」でも、カードによって、結果が分かれました。

## 「利用付帯」と「自動付帯」の違い

![自動付帯と利用付帯の違いの図。自動付帯はカードを持っているだけで保険が付く。利用付帯は、そのカードで電車や航空券などを払うと保険が付く](/images/ins-1-futai.jpg)
<em class="cap">自動付帯と利用付帯の違いです（すみまる作のイラスト）。</em>

- 自動付帯： カードを持っているだけで、保険が付きます。
- 利用付帯： 旅行代金や交通費を、そのカードで払ったときに、保険が付きます。

カード会社は、少しずつ、利用付帯に変えています。「持っているカードに保険がついている」と思っていても、条件を満たしていないと、使えません。 私のマレーシアの経験が、そうでした。

## 条件の違い（公式ページより）

| | リクルートカード（Visa・Mastercard） | エポスカード（Visa付／ゴールド） |
|---|---|---|
| 付帯の方式 | 利用付帯 | 利用付帯 |
| 出国前の支払い | 対象：空港へ向かう電車・バス・タクシー、航空券、パッケージツアーなど | 対象：ツアー代金、公共交通機関の乗車券・乗車代金 |
| 出国後の支払い | 対象外（公式ページの現在の記載） | 対象（公共交通機関の乗車代金。払った時から90日） |

<em class="cap">3枚のカードを、出国前・出国後の支払いで比べた表です（公式ページの記載より）。</em>

## 補償額の違い（公式ページより）

| | リクルートカード | エポスカード（Visa付） | エポスゴールド |
|---|---|---|---|
| 傷害死亡・後遺障害 | 最高2,000万円 | 最高3,000万円 | 最高5,000万円 |
| 傷害の治療費用 | 100万円 | 200万円（1事故） | 300万円（1事故） |
| 疾病の治療費用 | 100万円 | 270万円（1疾病） | 300万円（1疾病） |
| 賠償責任 | 2,000万円 | 3,000万円 | 5,000万円 |
| 携行品損害 | 1旅行20万円まで | 20万円 | 50万円 |

- 治療費用の補償額は、エポスのほうが、大きいです。
- 家族は、原則として、対象外です。ただし、エポスは、同じ種類のカード同士なら、代表者がまとめて払えば、同伴者にも適用されると書かれています。

## エポスカード（Visa）の保険を、くわしく

リンク先で申し込めるのは、エポスカード（Visa）です。公式ページ（2026年11月4日に確認）に書かれていた、海外旅行傷害保険の内容を、まとめます。

| 項目 | エポスカード（Visa） |
|---|---|
| 付帯の方式 | 利用付帯 |
| 保険が適用される条件（どれか1つ） | ①出国前にツアー代金を払う ②出国前に公共交通機関の乗車券を予約して払う ③出国前に公共交通機関の乗車代金を払う ④出国後に公共交通機関の乗車代金を払う |
| 補償の期間 | 出国前に払った場合：旅行開始から90日間（かつ旅行期間中）／出国後に払った場合：払った時から90日間（かつ旅行期間中） |
| 傷害死亡・後遺障害 | 最高3,000万円 |
| 傷害の治療費用 | 200万円（1事故） |
| 疾病の治療費用 | 270万円（1疾病） |
| 賠償責任 | 3,000万円（1事故） |
| 救援者費用 | 100万円 |
| 携行品損害 | 20万円（自己負担額3,000円） |
| 家族 | 対象は本人のみ。ただし、同じ種類のカード同士なら、代表者がまとめて払うと、同伴者にも適用される |

- 出国後に公共交通機関の乗車代金を払えば、利用付帯の保険が適用される条件は、エポスカード（Visa）も、エポスゴールドと同じです。 公式ページの利用付帯のQ&Aは、Visaとゴールドの共通の項目として、書かれています。
- ゴールドとの違いは、補償額です。ゴールドのほうが、治療費用や携行品が大きくなります（上の補償額の表を見てください）。
- 払った時から補償が始まる点（払う前は対象外）も、同じです。
- 条件と補償額は、変わることがあります。申し込む前に、[公式ページ](https://www.eposcard.co.jp/insurance/oversea_insurance.html)で、最新の内容を確認してください。

## Amazon Mastercardは、どう考えるか

Amazon Mastercard（私が持っていたのは、クラシック）は、三井住友カードが発行しています。マレーシアの病院で、このカードで支払いましたが、保険は適用されず、自腹になりました（くわしくは、[こちらの記事](/articles/travel-insurance-card-kl)に書いています）。

そのあとで、あらためて公式ページを調べて、確認できたのは、次のことです（2026年11月4日）。

- Amazonの公式ページに、「最高2,000万円の海外旅行傷害保険」「事前に旅費などを当該カードで支払うことが前提」と書かれています。
- 同じページに、「2025年10月16日以降出発の旅行から、条件が変更される」とも書かれています。ただ、変更の中身は、そのページに書かれていません。
- 三井住友カードの公式のお知らせには、2025年10月16日以降の出発で、出国後の公共交通機関の支払いが条件から外れ、出国前に条件を満たす必要があると書かれています。ただし、そのお知らせの対象に、Amazon Mastercardが含まれるかは、ページから確認できませんでした。
- 補償額の内訳（治療費用など）は、Amazonのページには書かれていません。

つまり、Amazon Mastercardで「出国後の支払いで間に合うか」は、確認できていません。 持っている方は、出発前に、カード会社の保険のご案内で、今の条件を確認してください。私は、出国前に、空港までの電車代などをカードで払っておくのが、いちばん安全だと考えています。

## 私の使い方

- 私は、旅の途中で、現地の公共交通機関を、エポスゴールドで払いました。この払いで、エポスの利用付帯の条件を満たしていたことになります。
- ただし、保険を実際に使ったことは、ありません。 この記事は、公式ページの条件と、私が払った事実を並べたものです。「保険が確実に使える」と言うものでは、ありません。
- 補償は、払った時から始まります。払う前に起きたことは、対象になりません。この点が、とても大事だと思います。

<em class="cap">払う前は対象外で、払った時から補償が始まります（エポスの場合）。</em>

## 出発前の確認リスト

1. 持っているカードの保険が、自動付帯か、利用付帯かを、カード会社の公式ページで見る。
2. 利用付帯なら、出国前に払うのか、出国後でもよいのかを見る。
3. 条件に当たる支払い（空港までの電車、航空券など）を、そのカードで払う。
4. 払った日が分かる明細を、残しておく。
5. ページの改定日を見る。カード会社は、予告なく変更することがあります。
6. 補償額（特に治療費用）が、行く国に足りるかを見る。


![出発前に確認する4つのこと。付き方を見る、払う時期を見る、そのカードで払う、明細と日付を残す](/images/ins-4-checklist.jpg)
<em class="cap">出発前の確認を、4つにまとめました。</em>

## エポスカードをこれから作る方へ

エポスカードの保険に興味を持たれた方は、公式の案内を、一度見てみてください。

- リンク先で申し込めるのは、エポスカード（Visa）です。私が持っているゴールドでは、ありません。ただ、出国後の公共交通機関の支払いで利用付帯が適用される条件は、ゴールドと同じです。補償額は、上の表のとおり、違います。
- 初めてエポスカードを申し込む方が、対象のサービスです。
- 日本にいるうちに、お申し込みください。海外からの申し込みは、対象外とされています。
- 申し込む前に、公式ページで、年会費と、保険の最新の条件を確認してください。
